# Actividad 1: Algoritmos de aprendizaje automático

## Descripción

Diagnóstico, limpieza y preparación del Student Performance Factors Dataset para una posible tarea posterior de regresión.

## Objetivo

Aplicar técnicas de exploración, limpieza, codificación y escalamiento para obtener un conjunto de datos preparado para aprendizaje automático.

## Archivos

- `Actividad1_APA.ipynb`: notebook ejecutado y documentado.
- `StudentPerformanceFactors.csv`: conjunto de datos original.
- `csv_limpio.csv`: conjunto de datos limpio y transformado.

## Dataset

Abdel-Ghany, M. (2025). *Student Performance Factors Dataset*. Kaggle.

https://www.kaggle.com/datasets/mosapabdelghany/student-performance-factors-dataset

## Herramientas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Ejecución

El notebook puede abrirse y ejecutarse en Google Colab o Jupyter Notebook.
